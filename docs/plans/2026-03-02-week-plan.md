## 关键决策树

```
E5 结果？
├── mAP ≥ 89.5% → 直接达标，重点展示 re-ranking 的作用
└── mAP < 89.5% → 继续等待 E1

E1 结果？
├── mAP ≥ 89.4% → 复现论文指标，组会重点讲配置差异分析
└── mAP < 89.0% → 做 E1+reranking 组合，大概率补足差距

E3 结果？
├── 优于 B5 → 展示 scheduled I2T 的有效性（新贡献点）
└── 不及 B5 → 排除课程学习路线，结论也有价值
```

- E5：92.3%，命中“快速提升”路径；
- E1：baseline 提升有限（88.9%），但 E1+reranking 达到 92.5%（本周最优）；
- E3：显著低于 B5，课程学习路线已排除；
- D1c（contrastive）：baseline 仅 86.2%，判定为非最优；
- D1c（combined）：baseline 86.4%、reranking 90.8%，同样非最优；
